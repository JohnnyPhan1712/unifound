# Tài liệu UniFound

Tài liệu được chia theo ba mục đích, không có thư mục `current_system` riêng.

| Thư mục | Vai trò |
|---|---|
| [`00_guides/`](00_guides/) | Quy ước, workflow và định hướng dùng chung |
| [`01_changes/`](01_changes/README.md) | Một hồ sơ cho mỗi công việc đáng kể |
| [`02_reports/`](02_reports/README.md) | Product Brief và trạng thái dự án đã kiểm chứng |

## Thứ tự đọc

`AGENT.md` → `docs/README.md` → report liên quan → guide liên quan → `01_changes/README.md`.

## Nguyên tắc

- Report là nguồn chính để xem tình hình hiện tại; không lặp lại thành một bộ tài liệu hiện trạng khác.
- Nội dung chưa chốt dùng `TBD`, `Draft` hoặc `Planned`.
- Một thông tin chỉ có một nguồn chính; file khác dùng liên kết.
- Mỗi CHG ánh xạ với một Task Notion; các file được sửa là Document liên quan của Task đó.
- Chỉ đánh dấu hoàn thành khi có kết quả kiểm tra hoặc bằng chứng phù hợp.
